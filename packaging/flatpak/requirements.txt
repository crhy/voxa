# Pin the 1.x hub. The pre-1.0 hub (0.28.1) crashes when faster-whisper passes its
# own disabled_tqdm (a subclass of tqdm.auto.tqdm) as tqdm_class: in a non-TTY
# (Flatpak/GUI) environment tqdm.auto resolves to the asyncio variant, which never
# has tqdm's class-level _lock set, and 0.28.1 reads tqdm_class._lock unguarded
# ("type object 'disabled_tqdm' has no attribute '_lock'). The 1.x hub guards the
# lock access, so the speech model loads. Cost: pulls hf-xet and the httpx stack
# (a few MB) instead of requests/urllib3/charset_normalizer.
# NOTE: python3-requirements-flatpak.json is committed. When changing this file,
# regenerate it (see .github/workflows/build.yml); at this pin the generator pulls
# httpx and hf-xet rather than splitting requests/urllib3/charset_normalizer out.
