**Update 2026-10-07 21:30 — echo lab root cause found (supersedes the "capture path" guess above):** the Blue USB microphone and the onboard card run on different hardware sample clocks; the delay between them drifts 0.32 samples/s at 16 kHz (20 ppm), dead straight. A fixed delay over a 15 s clip leaves coherence 0.15 at 2–3 kHz; following the drift gives 0.84–0.95 in every band. A shared GStreamer clock (q12) does not help; the lab's old coherence/oracle numbers were wrong on real data. Recordings + reference script: `/Voxa/.voxa-spec/out/anclab/drift/`. **How the work is run:** task prompts in `/Voxa/.voxa-spec/tasks/agent/*.md` (prefixed by `_header.md`), run one at a time by `run-step.sh` (gate = ruff + full pytest under xvfb). Queue runner: `.voxa-spec/out/fqueue.sh` reads names from `.voxa-spec/out/fqueue.list` (append while it runs; delete `fqueue.list.pos` before restarting with a new list; start with `setsid nohup`). A failed task STOPS the queue and leaves its changes in place (do not reintroduce the old discard-with-git-clean step — the permission classifier blocks it). Wait by counting `FQUEUE (END|STOPPED)` lines in status.txt; background waiters die after 30 minutes, so re-check directly. Start Strata with `strata-opencode-starter --model coder-iq1_m --server-only`; normal speed 55–65 tok/s. Prompts that worked best: exact file list, exact signatures, verified facts from the real machine, "do NOT open existing test files", a NEW test file per task. After each batch, try the feature for real (read-only where possible) — almost every batch had one fault only a real run showed.

**Real-app checks:** scripts in `/Voxa/.voxa-spec/out/` (`check_focus_app.py`, `check_flows.py`, `check_welcome.py`, `ui/session*.sh`); run them from a `git worktree` of HEAD when Strata is editing the tree.
