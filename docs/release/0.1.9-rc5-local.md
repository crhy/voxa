# Voxa 0.1.9 rc5 — local Flatpak (not published)

This is a **local test bundle** for 0.1.9, built from this checkout and **not** pushed to
Flathub or the GitHub Pages repo. It is rc4 plus the fixes from issue #72 (branch
`strata/v08-voxa-never-hears-herself`) that make sure **Voxa never hears herself**: one
continuous reference for a whole reply, a text veto that reads her whole turn instead of the
current piece, and an Ollama settings fix. Use it to try the hearing loop with DTLN on your own
machine; it never auto-updates and never overwrites the Flathub 0.1.8 you had.

## What is in it

Everything in rc4 (`docs/release/0.1.9-rc4-local.md`): APP_VERSION `0.1.9`, the whole hearing
chain (f163..f183, #72), the DTLN-aec default echo stage (h04), the rc2 loop fixes, the Ollama
installer gate and the three rc4 echo-ON fixes. New since rc4 (issue #72, "never hears
herself"):

- **One reply is ONE continuous reference and one turn (`voxa/timeline.py`, `voxa/audio.py`,
  `voxa/hearing.py`, `voxa/window.py`, `voxa/bargectl.py`).** rc4's reference was continuous
  per piece: between two pieces of one reply the reference went silent, and attribution saw a
  gap it could mistake for new speech. The timeline now opens a **turn** when a reply starts
  and closes it 1.5 s after the last piece ends (`turn_reference_window`,
  `ECHO_TAIL_SECONDS`); attribution and the barge-in guard both read that window, so during a
  whole reply — including the gaps between pieces — anything the microphone hears that matches
  what she is saying is her own voice, never an interrupt. The director announces
  `TurnStarted`/`PieceSpoken` so the barge-in controller knows which turn it is vetting.
- **The text veto reads her whole turn, not the current piece (`voxa/bargectl.py`).** The echo
  veto compared the heard line only against the piece playing right now, so a long echo of an
  earlier sentence of the same reply could interrupt her. The veto now reads
  `turn_veto_text()` — everything said since the turn opened, plus previous-turn evidence for
  10 s after the turn closes — with the same narrowness rule: heavy overlap (>= 0.5) plus
  letter-shape similarity (>= 0.55) plus at most **three** words that are not hers
  (`_VETO_FOREIGN_CONTENT_MAX = 3`) plus hers-dominant. The literal wake word is exempt: a
  line that names Voxa is treated as speech to her once the wake word is stripped.
- **A replay gate over the rc4 live log (`tools/self_hearing_replay.py`).** The rc4 live run's
  own log (`tests/fixtures/selfhearing-rc4-live.log`, hand-labelled echo/user lines in
  `tests/fixtures/selfhearing-rc4-live.labels.json`) is replayed through the real
  `BargeInController`: **17 echo lines produce 0 self-interrupts** (rc4's own log showed 3 of
  them interrupting her mid-reply), and **all 47 user lines survive** — none is swallowed as
  her own voice. Evidence is rebuilt from the controller's own turn state; nothing is
  fabricated (no invented VAD scores).
- **An untagged saved Ollama name matches its `:latest` tag (`voxa/ollama.py`,
  `voxa/window.py`).** If the saved model name had no tag and the installed list contained its
  tagged twin (`qwen3` saved, `qwen3:latest` installed), the settings dropdown fell back to the
  first installed model. `installed_choice()` now resolves the untagged name to its tagged
  twin, and the dropdown keeps showing the model Voxa actually runs.

## Tests in this build

- Python suite: **4354 passed, 60 skipped** (`/Voxa/.venv/bin/python3 -m pytest -q -p
  no:cacheprovider tests`) — rc4's 4338 plus the regression tests below; each fails on the old
  code and passes on the new.
  - `tests/test_render_reference_turn.py` (one continuous reference): drives the real GStreamer
    in a subprocess over both speech paths and shows the reference and the attribution window
    stay open across the gaps inside one reply. It fails on rc4 exactly where the live run
    failed: 33 momentary "reference silent" violations on the piece path (23 on the
    whole-reply path).
  - `tests/test_bargein_turn_wide_veto.py` (whole-turn veto): the logged lemonade and "honey"
    echoes of earlier pieces of the same reply stay OWN_VOICE across the gap and the 1.5 s
    echo tail, while "What is the capital of France? …" — four foreign words — still
    INTERRUPTS; previous-turn evidence is honoured for 10 s after the turn closes.
  - `tests/test_self_hearing_replay.py` (replay gate): runs the replay tool over the rc4 live
    log; requires `self-interrupts: 0 of 17 echo lines` and `user lines heard: 47 of 47`.
  - `tests/test_ollama_installed_choice.py` (Ollama tag fix): the untagged saved name resolves
    to its `:latest` twin; a genuinely different saved name still falls back to the first
    installed model.
- `python3 tools/release_check.py`: **OK** — `release metadata OK: version 0.1.9, bundle
  Voxa-0.1.9-x86_64.flatpak`.

## Install this bundle

```
flatpak install --user --bundle /home/rhy/Voxa-0.1.9-rc5-local.flatpak
```

It shares the app id `io.github.crhy.voxa` with the Flathub app, so installing it takes the
place of your 0.1.8 (or an earlier local rc) for the desktop entry. It is a one-off local
install: it will not update itself from a remote.
