# Voxa 0.1.9 rc2 — local Flatpak (not published)

This is a **local test bundle** for 0.1.9, built from this checkout and **not** pushed to
Flathub or the GitHub Pages repo. It is the 0.1.9 release candidate (rc1) plus three fleet
branches that landed after rc1. Use it to try the new hearing behaviour on your own machine;
it never auto-updates and never overwrites the Flathub 0.1.8 you had.

## What is in it

Everything in the 0.1.9 release candidate (rc1, `strata/v01-voxa-0-1-9-rc-build`): APP_VERSION
`0.1.9`, the whole hearing chain (f163..f183, #72) and every fleet branch that passed its gate
since 0.1.8 — see `docs/release/0.1.9.md`.

New since rc1 (merged into this rc2):

- **DTLN-aec neural echo stage (strata/h04-voxa-hearing2-ship-dtln-echo, #72).** `echo_mode`
  now defaults to `dtln`: a small on-device neural model removes the computer's own sound
  (Voxa's voice, music, video) before she listens. The two ONNX weights (`voxa/data/dtln/
  dtln_aec_512_1.onnx`, `dtln_aec_512_2.onnx`) ship inside the bundle; on a machine without
  onnxruntime or the weights Voxa falls back to her own NLMS canceller and says so, never
  crashing the capture.
- **Hands-free roadmap (strata/f208-voxa-handsfree-roadmap, #68).** Adds `docs/ROADMAP.md`,
  marking what is already shipped toward Voxa as a hands-free personal assistant. Docs only.
- **Ollama installer verification (strata/f218-voxa-verify-ollama-install, #132).** This branch
  is a competing implementation of the same #132 gate that rc1 already ships via
  strata/f021-voxa-verify-ollama-script-before-root. rc2 keeps rc1's more-integrated design
  (`PINNED_SCRIPT_DIGESTS`, `tools/pin_ollama_installer.py`, `docs/notes/voxa-verify-before-root.md`);
  f218 adds no code this branch does not already have.

## Install this bundle

```
flatpak install --user --bundle /home/rhy/Voxa-0.1.9-rc2-local.flatpak
```

It shares the app id `io.github.crhy.voxa` with the Flathub app, so installing it takes the
place of your 0.1.8 for the desktop entry. It is a one-off local install: it will not update
itself from a remote.

## Going back to Flathub 0.1.8

Uninstall the local bundle and reinstall the published one:

```
flatpak uninstall --user io.github.crhy.voxa
flatpak install --user flathub io.github.crhy.voxa
```

That restores the Bazaar/Flathub **0.1.8** and its normal update path. Your Voxa settings and
saved hearing profiles under `~/.var/app/io.github.crhy.voxa/` are left in place; if you want a
clean slate, remove that folder too.

## Caveats

- This bundle was **not** run with `flatpak run` or tested on a live desktop here (no microphone,
  no speakers opened, per the task rules). The Flathub/GH-Pages CI build remains authoritative.
- It was built with the local SVG-icon-validation workaround for the host's broken librsvg
  loader (see the fleet notes); the icon files themselves are unchanged.
