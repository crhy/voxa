# Voxa 0.1.9 rc7 — local Flatpak (not published)

Local test bundle for 0.1.9, built from branch `strata/v11b-voxa-live-tap-real-sink`
(issue #72 task v11b) and **not** pushed to Flathub. It is rc6 plus the v11b render-tap fixes.
It never auto-updates and never overwrites an earlier local rc.

**Status: a work in progress.** The real-sink tap is fixed and reports for every reply
(steps 1-4 done, numbers below). Steps 8-10 are **not done**: with the reference live and
non-silent, the echo-path alignment still never fits, and the degraded turn-wide text veto
promotes her own garbled echo — 4 self-interrupts in 30 s while she spoke alone.

## What is in it (v11b)

- **The reply reports its render tap (voxa/window.py).** `_note_reply_start` /
  `_note_reply_end` are idempotent per reply; `_conversation_speak` closes the reply's audio
  bookkeeping **ungated** (`_reply_audio_end`) before the session-gated callback, and the
  barge-in (`INTERRUPT`) path calls `_note_reply_end` like any other end. On base the session
  token gate dropped the done callback (a talk-over or a follow-up arms) and the reply wrote
  **no** `render-tap` line and left its render turn open; an interrupted reply never closed
  either.
- **A live turn's reference never reads silent when the render map runs off
  (voxa/timeline.py `turn_reference_window`).** The estimated map can place the microphone
  moment outside what the render ring holds (a whole-reply is queued to the sink ahead of the
  clock that stamps its chunks); the old code zero-padded — silence for an audibly playing
  reply — which is exactly the live `reference active by definition while speaking: silent tap`.
- **Regression tests.** `tests/test_render_tap_real_sink.py` drives the real production
  `MainWindow` (GTK-capable subprocess; fake audio and speech) and fails on base: token-dropped
  and interrupted replies write no `render-tap` line and leave `state='open'`.
  `tests/test_render_reference_turn_window_map.py` reproduces the queue-ahead map and fails on
  base.

### NOT met: alignment and the degraded promote (steps 8-9)

Same 36 s window, her voice alone at the microphone (nobody else talking):

## Build note (local bundle only)

The local `flatpak-builder` export fails validating `io.github.crhy.voxa-symbolic.svg`
("Format not recognized") on this machine. To build the local bundle the symbolic-icon install
line was removed from the manifest just for the bundle build and restored afterwards
(`git checkout -- io.github.crhy.voxa.yml`); the committed manifest is unchanged.
Builder: `env XDG_DATA_HOME=/home/rhy/.local/share flatpak-builder --ccache --repo=.build/repo
.build/rc7b io.github.crhy.voxa.yml`, then `flatpak build-bundle .build/repo
/home/rhy/Voxa-0.1.9-rc7-local.flatpak io.github.crhy.voxa master`.
